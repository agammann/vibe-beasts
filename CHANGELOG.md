# Changes

## 1.2.0

- Keep unreadable Windows saves unchanged until a player imports a valid backup or explicitly chooses a new egg. Failed saves retain the previous good file.
- Resolve Windows sprites, icons and exported backups beside the executable, including launches from another directory. Failed snapshot writes and malformed command options report failure.
- Handle a browser import file that cannot be read without replacing progress.
- Pair the source, browser and Windows packages with exact source identities, build receipts and checksums. Build and check the delivered source in pinned CI.
- Correct the Windows instructions to cover all 151 species and 79 partner families. Original Pokémon artwork and trademark rights remain separate from the MIT code license.

## 1.1.0

The historical Windows release remains available without replacement.
